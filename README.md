# Справочник O-RADS US — сайт-приложение (orads.timofeeva-online.ru)

Бесплатная схема без сервера:
- Этот репозиторий публикуется через GitHub Pages: оболочка сайта, `sw.js` (работа без сети), значок.
- Сам справочник лежит **зашифрованным** в «Файлах» Prodamus (con.xl.ru). Здесь его открытого текста нет.
- Ключ выдаёт урок «Справочник O-RADS US» в школе (доступ проверяет Prodamus), вместе с датой окончания подписки ученика.
- Робот `.github/workflows/rotate.yml` раз в 3 дня меняет ключ и файл (`tools/rotate.mjs`), секрет `API_TOKEN`.

Обновить справочник: зашифровать новый текст ТЕКУЩИМ ключом из урока и закоммитить как `update.enc` — робот запустится сам.
